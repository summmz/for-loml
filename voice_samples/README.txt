Put your voice recording here for the cloned-voice TTS.

Requirements for the sample (voice_samples/nini.wav):
  - 6-10 seconds long, clear, no background noise
  - Speak naturally, like how you'd actually talk
  - Record in WAV format (16-bit, mono or stereo)

Everything else is optional; you can also use this to check status:
  - tts_server.py expects the file next to it in voice_samples/

Start the server, then open: http://127.0.0.1:5001/

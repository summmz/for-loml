Leave her a note 💌

Sends straight into her app — shows up in the Notes panel next time it polls.

How this works

This is a standalone page — it doesn't need the app's dev server or a rebuild. It posts your note to a private ntfy.sh topic; her app polls that same topic every couple minutes and shows anything new in the Notes panel. Use the same topic string you set as VITE_NTFY_NOTES_TOPIC in the app's .env. Keep the topic name private — anyone who knows it can publish a note that shows up as if it's from you.
